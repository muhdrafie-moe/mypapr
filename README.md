# MyEviden — Perekodan Evidens Murid MBPK

*(dahulu MYPAPR)* Mampat video & gambar, kolaj, edit gambar & video, fokus kepala & muka, rekod manual (Ketik Langkah / Seret), potong & gabung video, Galeri Saya dan Jana URL. Berfungsi tanpa internet (kecuali Jana URL).

## Windows 10/11 (versi 1.5.0)
1. Klik butang hijau **`<> Code`** → **Download ZIP**.
2. Buka folder **Downloads** → klik kanan **mypapr-main.zip** → **Extract All** → **Extract**.
3. Klik dua kali **PASANG-MYEVIDEN.bat** (jika keluar *"Windows protected your PC"*: **More info** → **Run anyway**).
4. Pemasang **MyEviden-Setup-1.5.0.exe** dibuka sendiri — ikut langkahnya. MyEviden menggantikan MYPAPR lama; tetapan & Galeri dikekalkan.

## Android
Muat turun **[MyEviden-1.5.0.apk](MyEviden-1.5.0.apk)** (klik fail → butang muat turun ⬇), salin ke telefon dan pasang.
